What this removes vs the static test: The earlier "screener top 20" backtest screened today then backtested 2024 — that is look-ahead bias (the 2024 strategy "knew" which stocks were strong in 2025). Here, at every month-end we re-screen using only data ≤ that date, and trade the result next month. The stock universe is therefore point-in-time.
Remaining known biases (v1, per reviewer):
  • Survivorship bias: universe = current S&P 500 + NASDAQ 100. Delisted/acquired names are absent → optimistic.
  • Market-cap approximation: no historical market cap fetched; index membership is the large-cap proxy. Market-cap filter is intentionally skipped.
  • Point-in-time index membership: we assume today's constituents existed throughout. A stock added to the index in 2023 is still screened in 2019 (extra history just makes it pass RS more often).

How to read this

Compare variants on MaxDD (did the regime filter reduce drawdown?), PF (edge quality), and Exposure% (how often was capital deployed). Higher return alone is not the goal — the regime engine's job is risk control during bad markets, which a bull-market window (2024-2025) under-tests.
